# Otel Rezervasyon ve Konaklama Yönetim Sistemi

Veri Tabanı Yönetim Sistemleri dersi 2026-2027 dönem projesi.

Bir otel işletmesinin rezervasyon, konaklama, ödeme, ek hizmet ve personel süreçlerini yöneten; Flask (Python) ile geliştirilmiş REST API'ye ve MySQL veri tabanına sahip bir otomasyon sistemidir.
